# Roteiro GitFlow
1. Criar `develop` a partir de `main`.
2. Criar features a partir de `develop`.
3. Abrir PR de cada feature para `develop` após testes.
4. Criar PR de `develop` para `main` para a release.
5. Criar tag `v1.0.0` somente após a versão estável.

Sugestões de commits:
- feat: implementa melhorias de acessibilidade
- perf: otimiza recursos da aplicacao
- fix: corrige navegacao e formularios
- docs: atualiza documentacao do projeto
